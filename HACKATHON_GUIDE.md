# ВСМ-1 «Белый кречет» — Инструкция для жюри хакатона

## Интерактивный тренажер поездных бригад с генеративным диалоговым ИИ и Neural Voice

Проект представляет собой тренажер поездных бригад высокоскоростной железнодорожной магистрали **ВСМ-1 Москва — Санкт-Петербург (скорость до 400 км/ч)** на базе интеллектуальной диалоговой платформы:

1. **Диалоговая языковая модель** — генеративный интерактивный диалог, живая реакция пассажиров, физическая симуляция поезда и объективное судейство на соответствие стандартам ВСМ.
2. **Бортовой речевой комплекс ВСМ (ASR / Neural TTS)** — распознавание русской речи проводника и многоголосый синтез персонажей/машиниста/систем.
3. **Корпоративный ID OAuth 2.0** — авторизация поездных экипажей в один клик.
4. **Интерактивная панель оборудования поезда** — тактильные физические действия проводника в игровом мире (стоп-кран, огнетушитель ОВП-8, электрощит СКНБ, медаптечка и АНД, терминал УКЭБ, чайный сервис).

## Быстрый запуск проекта

### Вариант 1: Запуск готового образа из Docker Hub в 1 команду (Рекомендуемый)

```bash
docker run -d -p 8000:8000 --name vsm-simulator msgcg/vsm-simulator:latest
```

Сервер будет доступен по адресу: **http://localhost:8000/**
Интерактивная документация Swagger UI: **http://localhost:8000/api/docs/**

Остановка контейнера:

```bash
docker stop vsm-simulator
```

### Вариант 2: Локальная сборка через Docker Compose

```bash
# 1. Сборка и запуск контейнера в фоновом режиме
docker compose up -d --build

# 2. Проверка статуса контейнера и логов
docker compose ps
docker compose logs -f web
```

Остановка контейнера:

```bash
docker compose down
```

### Вариант 3: Локальный запуск через виртуальное окружение Python (venv)

```bash
# 1. Клонирование репозитория
git clone https://github.com/msgcg/VSM_game.git
cd VSM_game

# 2. Создание и активация виртуального окружения
python -m venv .venv
.\.venv\Scripts\Activate.ps1    # Для Windows PowerShell
# source .venv/bin/activate     # Для Linux / macOS

# 3. Установка зависимостей
pip install -r requirements.txt

# 4. Применение миграций базы данных
python manage.py migrate

# 5. Запуск веб-сервера
python manage.py runserver 127.0.0.1:8000
```

После запуска откройте в браузере: **http://127.0.0.1:8000/**

## Конфигурация окружения (.env)

Файл `.env` настраивается в корне проекта. Для работы локальной симуляции и тестов внешние API-ключи опциональны (система имеет встроенные заглушки и оффлайн-режим):

```env
# AI Platform (LLM)
GIGACHAT_CLIENT_ID=your_client_id_here
GIGACHAT_CLIENT_SECRET=your_client_secret_here
GIGACHAT_AUTH_KEY=your_base64_auth_key_here
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat-Max

# Corporate ID OAuth 2.0
SBER_ID_CLIENT_ID=your_sber_id_client_id
SBER_ID_CLIENT_SECRET=your_sber_id_client_secret
SBER_ID_REDIRECT_URI=http://127.0.0.1:8000/auth/sber/callback/
```

## Архитектура интерактивного диалога и бортового радиокомплекса

Вместо заготовленных статических тестов игрок оказывается в интерактивной среде, где каждое действие проводника и работа с оборудованием вагона оцениваются по стандартам ВСМ.

### Каналы взаимодействия:

1. **Голосовой радиоэфир (Бортовой комплекс ASR)**:
   - Нажмите кнопку микрофона на пульте.
   - Произнесите реплику проводника на русском языке. Текст автоматически фиксируется в диалоговой ленте.
2. **Свободный ввод текста**:
   - Введите любую фразу проводника или команду поездной бригаде в поле ввода.
3. **Физическое оборудование вагона (6 ключевых предметов)**:
   - **Рукоятка стоп-крана** — экстренное торможение поезда (судья строго проверяет запрет срыва на мостах и в тоннелях!).
   - **Огнетушитель ОВП-8** — пожаротушение в тамбуре и купе.
   - **Электрощит вагона** — осмотр датчиков СКНБ, контроль ламп «Земля», перезапуск автомата климата.
   - **Медаптечка и Дефибриллятор АНД** — первая помощь при инфаркте, гипертонии и травмах.
   - **Терминал УКЭБ** — сканирование электронных билетов, проверка документов и оформление актов.
   - **Чайный сервис** — подача фирменного чая в подстаканнике / воды с лимоном для деэскалации стресса.
4. **Быстрые регламентные решения**:
   - Регламентные действия из стандартов ВСМ для оперативного реагирования в условиях дефицита времени.

## Таймер критического решения

В проекте реализована точная логика учета времени:

- Таймер не расходуется во время обращения к серверу.
- Таймер приостанавливается во время воспроизведения речи персонажа.
- Таймер останавливается во время голосовой записи проводника.
- Обратный отсчет включается в момент передачи хода проводнику.

## Озвучка персонажей поезда (TTS)

Персонажи озвучиваются нейросетевым многоголосым движком:

- Женские голоса пассажиров: эмоциональная палитра разной степени напряженности.
- Мужские голоса пассажиров: нейтральные и требовательные интонации.
- Машинист поезда по радио: низкий тембр с характерным эффектом радиосвязи.
- При отсутствии подключения к сети автоматически используется браузерный Web Speech API.

## Нормативная база и судейство

ИИ-оценка и обучающий дебрифинг опираются на официальные стандарты ВСМ и нормативные документы ВСМ-1:

- **СТО ВСМ 03.011-2026** — Стандарты обслуживания и этикет проводников ВСМ «Белый кречет».
- **СТО ВСМ 03.013-2026** — Регламенты взаимодействия экипажей при ЧС и инцидентах.
- **СТО ВСМ 03.014-2026** — Правила обслуживания маломобильных пассажиров (МГН).
- **ПТЭ железных дорог РФ** — Правила технической эксплуатации на высокоскоростных участках.
- **4-шаговая модель ВСМ**: *Признать ситуацию* -> *Обозначить правило* -> *Предложить решение* -> *Заверить*.
