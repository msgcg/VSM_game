# ВСМ-1 «Белый кречет» — Интерактивный симуляционно-обучающий комплекс поездных бригад

Официальная платформа профессиональной подготовки и аттестации проводников Высокоскоростной железнодорожной магистрали Москва — Санкт-Петербург (ВСМ-1).
Скорость движения: **до 400 км/ч** | Нормативная база: **СТО ВСМ 03.011–2026, 03.013–2026, 03.014–2026, ПТЭ**

---

> ### Быстрый запуск комплекса в 1 команду (Docker Hub)
>
> ```bash
> docker run -d -p 8000:8000 --name vsm-simulator msgcg/vsm-simulator:latest
> ```
>
> После запуска комплекс доступен в браузере:
>
> - Главный пульт проводника: [http://localhost:8000/](http://localhost:8000/)
> - Интерактивная документация REST API (Swagger UI): [http://localhost:8000/api/docs/](http://localhost:8000/api/docs/)
> - Спецификация OpenAPI 3.0: [http://localhost:8000/api/v1/openapi.json](http://localhost:8000/api/v1/openapi.json)

## Краткое описание проекта

Высокоскоростная железнодорожная магистраль **ВСМ-1 «Москва — Санкт-Петербург»** предъявляет качественно новые требования к квалификации поездного персонала:

- Скорость движения состава **до 400 км/ч** сокращает допустимое время реакции проводника на нештатные ситуации до **8–25 секунд**.
- Обслуживание 4 классов комфорта (**Первый, Бизнес, Комфорт, Стандарт**) требует безупречного владения сервисным этикетом и методиками деэскалации конфликтов.
- Эксплуатация высокотехнологичного подвижного состава **«Белый кречет» (ЭВС2)** требует знания систем СПАС-ВО, сигнализации СКНБ, вакуумных модулей ЭЧТК и регламентов первой помощи.

Комплекс переводит пассивное изучение инструкций в **активный симуляционный тренинг**:

- Каждое задание представляет собой **интерактивный сюжетный кейс-сценарий** с репликами пассажиров, показаниями бортовых датчиков, физическим оборудованием вагона (стоп-кран, огнетушитель, СКНБ, дефибриллятор, УКЭБ, чайный сервис) и жестким лимитом времени.
- Все решения проводника оцениваются по **двойной шкале: Лояльность пассажиров (CSI) + Безопасность движения**.
- По завершении рейса формируется обучающий **дебрифинг по 4-шаговой ролевой модели ВСМ** (*Признать ситуацию -> Обозначить правило -> Предложить решение -> Заверить*) со ссылками на конкретные статьи СТО ВСМ.
- Результаты аккумулируются в **динамической Матрице 6 компетенций** с векторным SVG-радаром квалификации и автоматическими рекомендациями для закрытия зон роста.
- Экспресс-режим **«Карусель скоростных решений»** позволяет тренировать реакцию в непрерывной смене с ускорением от 250 до 400 км/ч и фиксацией безупречных рейсов.

## Ключевые функциональные модули

1. **Главный пульт проводника (`/`)**
   Квалификационный паспорт, текущий ранг, прогресс опыта, интерактивная карта трассы Москва — Санкт-Петербург, центр уведомлений со сгорающими баллами и звуковой интерком ВСМ.
2. **HUD-симулятор рейса (`/simulation/<id>/`)**
   Интерактивная панель приборов на скорости до 400 км/ч, таймер принятия решений (8-25 сек), интерактивный диалог с пассажиром, управление физическим оборудованием поезда.
3. **Обучающий дебрифинг и черный ящик (`/simulation/<id>/result/`)**
   Протокол рейса, разбор каждого шага по ролевой модели ВСМ, цитаты из стандартов СТО ВСМ 03.011, 03.013, 03.014, начисление опыта и квалификационных бейджей.
4. **Аналитический центр и Матрица компетенций (`/analytics/`)**
   SVG-радар готовности проводника относительно норматива 85%, индекс готовности, автоматический расчет зон профессионального роста и персональный подбор кейсов.
5. **Карусель скоростных решений (`/endless/`)**
   Экспресс-смена из 8 этапов с ростом скорости от 250 до 400 км/ч, стриками опыта и счетчиком безупречных смен.
6. **Библиотека нормативных документов (`/regulations/`)**
   Встроенная читалка стандартов СТО ВСМ, оглавления глав, скачивание официальных PDF напрямую из базы данных.
