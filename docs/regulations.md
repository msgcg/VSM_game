# Нормативная база и хранение документов в базе данных

Согласно техническому заданию и регламентам ВСМ, все официальные нормативные акты, отраслевые стандарты (СТО ВСМ), квалификационные сборники и методические пособия хранятся непосредственно в базе данных в виде бинарных строк base64.

## Модель RegulationDocument

Каждый нормативный документ представлен записью в таблице `RegulationDocument`:

- `key`: уникальный строковый идентификатор документа (slug).
- `title`: официальное наименование стандарта.
- `subtitle`: номер распоряжения ВСМ и дата утверждения.
- `category`: классификатор (standard, mobility, equipment, cases, exam, textbook).
- `badge` и `badge_color`: цветовая дифференциация в интерфейсе.
- `description`: краткая аннотация сферы применения.
- `file_name`: имя исходного PDF-файла для скачивания.
- `file_size_display`: читаемый размер файла.
- `file_base64`: полное бинарное содержимое PDF-документа, закодированное в base64.
- `chapters_data`: JSON-массив глав документа с аннотациями для быстрого поиска и навигации.
- `content_markdown`: структурированный текст документа в формате Markdown для встроенной читалки в браузере.

## Механизм потоковой отдачи документов

Для гарантии автономности и безопасности просмотр и скачивание PDF реализованы через прямое декодирование base64-строки из базы данных в поток оперативной памяти (`io.BytesIO`):

- URL скачивания: `/regulations/download/<doc_key>/`
- URL чтения статьи: `/regulations/<doc_key>/`
- API-эндпоинт: `/api/v1/regulations/<doc_key>/`

Сервер генерирует потоковый HTTP-ответ `FileResponse` с заголовками `Content-Type: application/pdf` и корректным именем файла в кодировке UTF-8. Приложение полностью работоспособно в контейнере даже при отсутствии локальных файлов на диске.

## Команда наполнения базы данных

Для первичного импорта и обновления нормативных документов используется менеджмент-команда Django:

```bash
python manage.py seed_regulations
```

Команда считывает официальные PDF-файлы из каталога `regulations_docs/`, кодирует их в base64 и обновляет записи в таблице `RegulationDocument`.
